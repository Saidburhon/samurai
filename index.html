ClubTime

An operating system for billiard and table-tennis clubs. Every table is timed, every drink is counted, every lamp is wired, and the owner sees it all in Telegram from anywhere in the world.

  • Session timers per table. Start now or back-date, split into named rounds, settle who pays what.
  • Bar inventory with orders, returns, stock and cost price, so you see real profit.
  • Branded thermal receipts with your socials as a QR code.
  • Tamper-proof reports: a Telegram message after every session and an Excel file at day's end.
  • Wi-Fi relays switch the lamp over each table on START and STOP.
